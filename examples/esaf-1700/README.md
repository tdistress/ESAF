# ESAF-1700 example pack (informative)

Non-normative instance sketches supporting
[ESAF-1700](../../data-model/ESAF-1700.md). Recording data in these formats
does not establish certification, compliance, or control satisfaction.

## Worksheets

| File | ESAF-1700 section |
|---|---|
| [entity-instances.example.md](entity-instances.example.md) | Core entities, entity contracts, relationship model, and ESAF-1500 cross-references |

The worksheet connects one capability, two systems, one shared asset,
accountable owners, a risk classification, a gate decision, an exception, and
ESAF-1500 evidence, assessment-result, and finding identifiers. It is an
illustrative record sketch, not JSON Schema or a new exchange contract.
