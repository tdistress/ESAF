# ESAF-1400 example pack (informative)

Non-normative samples supporting the informative
[ESAF-1400](../../implementation/ESAF-1400.md) implementation guide. Using
these materials does not establish certification, compliance, or control
satisfaction.

## Worksheets

| File | ESAF-1400 section |
|---|---|
| [adoption-vignette.example.md](adoption-vignette.example.md) | 5. Filled fictional walkthrough of adoption Steps 1–9 |
| [capability-control-mapping.example.md](capability-control-mapping.example.md) | 6. Multi-capability mapping with a stale-mapping scenario |

## Suggested use

1. Read the vignette to see the handoffs among scope, ownership,
   classification, architecture, controls, implementation, validation,
   assessment, and improvement.
2. Adapt the mapping columns to implementation working material while keeping
   authoritative ESAF identifiers and implementation-local product detail
   separate.
3. Reconcile mappings after material changes and before handing evidence to an
   ESAF-1500 assessment.

The fictional values are examples, not defaults or approved baselines.
Organizations remain responsible for selecting applicable requirements,
patterns, controls, evidence, and decision authorities.
