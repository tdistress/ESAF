# Recommended GitHub Labels

| Label | Purpose |
|---|---|
| `framework` | ESAF-1000 content |
| `control` | Control objectives, requirements, or enhancements |
| `architecture` | Reference architecture or design pattern |
| `governance` | Project or enterprise governance |
| `crosswalk` | External standards mappings |
| `profile` | Industry or jurisdiction profile |
| `assessment` | Assessment and maturity content |
| `documentation` | Editorial and documentation work |
| `draft` | Work not yet approved |
| `review` | Ready for formal review |
| `approved` | Approved but not necessarily published |
