# Project Management

This directory contains artifacts used to manage ESAF itself. Normative framework content does not belong here.

- `BRANCHING_STRATEGY.md` defines the Git workflow.
- `DECISION_LOG.md` records durable editorial and architectural decisions.
- `LABELS.md` defines the issue-label taxonomy.
- `MILESTONES.md` defines publication milestones.
- `RELEASE_PLAN.md` defines release gates.
- `BACKLOG.md` captures approved work not yet scheduled.
