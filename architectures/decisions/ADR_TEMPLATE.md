# Architecture Decision Record

## Metadata

| Field | Value |
|---|---|
| Decision ID | ADR-#### |
| Title | Concise decision title |
| Status | Proposed |
| Owner | Accountable architecture owner |
| Decision date | ISO 8601 date |
| Review triggers | Material conditions requiring reassessment |
| Supersedes | Prior decision identifier or none |

## Context

Describe the capability, forces, constraints, assumptions, trust boundaries, and reason a decision is required.

## Decision

State the selected option and the scope to which it applies.

## Alternatives considered

Describe viable alternatives and the reason each was not selected.

## Consequences

Describe benefits, limitations, risks, technical debt, provider dependencies, and operational effects.

## Controls affected

Identify ESAF control objectives, base controls, inherited controls, and control owners affected by the decision.

## Evidence and validation

Identify architecture views, tests, reviews, approvals, and operational evidence required to demonstrate the decision.

## Conditions and follow-up

Record time bounds, implementation conditions, monitoring, reassessment, exception references, and required follow-up decisions.
