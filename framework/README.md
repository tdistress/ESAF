# ESAF-1000 Enterprise Standard

`ESAF-1000.md` is the authoritative working source for the core enterprise standard.

The core standard defines management-system outcomes and normative requirements. Detailed technical controls belong in ESAF-1100; architecture patterns belong in ESAF-1200; implementation examples belong in ESAF-1400; assessment procedures belong in ESAF-1500.

Substantive changes require a change proposal, technical review, editorial review, and approval under project governance.
