# ESAF-1000 Enterprise Standard

`ESAF-1000.md` is the authoritative Working Draft source for the core enterprise
standard.

The core standard defines management-system outcomes and normative
requirements. Companion publications and Draft toolkit surfaces supply
operating detail without replacing ESAF-1000:

| Surface | Role |
|---|---|
| [ESAF-1100](../controls/ESAF-1100.md) | Control catalog and assessment procedures |
| [ESAF-1200](../architectures/ESAF-1200.md) | Reference architectures and design patterns |
| [ESAF-1300](../governance/ESAF-1300.md) | Governance processes, roles, and decision rights |
| [ESAF-1400](../implementation/ESAF-1400.md) | Non-normative implementation guidance |
| [ESAF-1500](../assessment/ESAF-1500.md) | Assessment methodology and maturity model |
| [ESAF-1600](../crosswalks/ESAF-1600.md) | Versioned standards crosswalks |
| [ESAF-1700](../data-model/ESAF-1700.md) | Enterprise AI governance data model |
| [ESAF-1800](../profiles/ESAF-1800.md) | Industry, jurisdiction, and risk profiles |
| [Assessment toolkit](../assessment/README.md) | Schemas, workbook, evidence catalog, and audit checklist |
| [Governance templates](../templates/README.md) | Draft risk, exception, decision, and retirement templates |

Terminology is aligned with the repository [glossary](../GLOSSARY.md).

Substantive changes require a change proposal, technical review, editorial
review, and approval under project governance.
