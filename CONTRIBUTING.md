# Contributing to ESAF

Thank you for contributing to the Enterprise Secure AI Framework. ESAF is a collaborative, vendor-neutral standards initiative.

## Contribution areas

- Framework and control language
- Reference architectures and design patterns
- Governance and assessment procedures
- Standards mappings and industry profiles
- Templates, examples, diagrams, and glossary terms

## Contribution principles

Contributions should be vendor-neutral, technology-agnostic, risk-based, auditable, implementable, and traceable to authoritative sources where practical.

## Workflow

1. Search existing issues and pull requests.
2. Open an issue for material normative, structural, or taxonomy changes.
3. Create a focused branch from `main`.
4. Follow [`STYLE_GUIDE.md`](STYLE_GUIDE.md).
5. Add or update tests and validation when tooling changes.
6. Open a pull request using the repository template.
7. Address technical and editorial review comments.

```text
Draft -> Technical Review -> Editorial Review -> Approval -> Publication
```

## Normative language

- **Shall** indicates a mandatory requirement.
- **Should** indicates a strong recommendation.
- **May** indicates an optional capability.

Avoid using these terms casually in informative guidance.

## Sources and mappings

Use authoritative sources. Crosswalk contributions shall follow [`crosswalks/METHODOLOGY.md`](crosswalks/METHODOLOGY.md) and identify the external standard version.
