# MON-130 Agent Monitoring

## Requirement

The organization shall monitor agent identity, plans where available, tool calls, permissions, delegation, memory, actions, resource use, errors, interventions, and outcomes for behavior outside approved boundaries.

## Intent

Agent monitoring must identify anomalous action and authority use, not only response quality.

## Applicability

Applies to all agents and multi-agent systems, with real-time safeguards for high-impact actions.

## Implementation guidance

Establish agent baselines, sequence and rate rules, prohibited-action alerts, privilege changes, loop detection, resource ceilings, and oversight telemetry.

## Expected evidence

- Monitoring design, baselines, rules, dashboards, intervention signals, tests, alerts, and investigations.

## Assessment procedures

- **MON-130-A1 - Examine:** Verify coverage of required agent event categories.
- **MON-130-A2 - Test:** Simulate unauthorized actions, delegation, loops, and resource abuse.
