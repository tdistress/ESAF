# MON-110 AI Security Detection

## Requirement

The organization shall detect and investigate risk-relevant AI security events, including unauthorized access or change, prompt and context attacks, data exposure, model abuse, extraction, tool misuse, agent escalation, policy evasion, and anomalous consumption.

## Intent

AI attacks may appear in prompts, retrieval, behavior, tools, or resource patterns rather than conventional endpoint alerts.

## Applicability

Applies to in-scope AI services and supporting security telemetry.

## Implementation guidance

Develop use cases from threat models, tests, intelligence, incidents, and baselines. Correlate identity, gateway, application, model, data, tool, infrastructure, and provider signals.

## Expected evidence

- Detection catalog, logic, sources, thresholds, tests, tuning, alerts, investigations, and coverage reviews.

## Assessment procedures

- **MON-110-A1 - Examine:** Verify detection coverage against approved threat cases.
- **MON-110-A2 - Test:** Simulate representative events and confirm alert generation.
