# INF-130 AI Infrastructure Configuration and Change

## Requirement

The organization shall define infrastructure as controlled, versioned, reviewed, tested, approved, reproducible, monitored configuration and maintain rollback or recovery for changes affecting AI workloads.

## Intent

Reproducible configuration reduces drift, unauthorized change, and recovery uncertainty.

## Applicability

Applies to infrastructure code, images, policies, networks, storage, orchestration, model-serving configuration, and managed-service settings.

## Implementation guidance

Use protected source, peer review, automated tests, signed artifacts, deployment separation, policy validation, canaries, drift monitoring, and emergency-change review. Record provider-console changes.

## Expected evidence

- Configuration repositories, reviews, tests, approvals, deployment logs, drift results, rollback tests, and emergency records.

## Assessment procedures

- **INF-130-A1 - Examine:** Verify controlled configuration and approval for sampled components.
- **INF-130-A2 - Test:** Reproduce a representative environment from approved configuration.
- **INF-130-A3 - Test:** Compare running state with approved source and investigate drift.
