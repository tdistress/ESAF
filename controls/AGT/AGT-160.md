# AGT-160 Multi-Agent Control

## Requirement

The organization shall govern multi-agent identity, communication, delegation, authority propagation, shared state, conflict resolution, termination, and emergent behavior through explicit architecture and enforceable boundaries.

## Intent

Agent interactions can amplify permissions, obscure accountability, create loops, and produce behavior absent from individual-agent testing.

## Applicability

Applies when agents communicate, supervise, delegate to, compete with, or create other agents.

## Implementation guidance

Use authenticated channels, delegation depth and duration limits, non-transitive authority by default, loop and fan-out limits, shared-state controls, conflict policy, global intervention, and system-level testing.

## Expected evidence

- Multi-agent architecture, identities, communication policy, delegation rules, shared-state design, emergent-behavior tests, and intervention results.

## Assessment procedures

- **AGT-160-A1 - Examine:** Verify explicit multi-agent boundaries and accountability.
- **AGT-160-A2 - Test:** Attempt unauthorized privilege propagation and excessive delegation.
- **AGT-160-A3 - Test:** Exercise loops, conflicts, fan-out, and global termination.
