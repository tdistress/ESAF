# AGT-110 Agent Permission and Delegation Boundaries

## Requirement

The organization shall constrain each agent's data, tools, targets, actions, resources, duration, delegation, and side effects to explicitly approved permissions enforced outside the model.

## Intent

Prompt instructions alone cannot reliably enforce agent authority or prevent excessive agency.

## Applicability

Applies to direct action, tool invocation, subagents, scheduled work, callbacks, code execution, transactions, and external communication.

## Implementation guidance

Default to deny, use scoped credentials and allowlists, authorize at each tool and target, limit runtime and spend, prevent privilege propagation, and require new approval for expanded scope.

## Expected evidence

- Permission model, credentials, tool policy, delegation rules, limits, authorization tests, and denied-action logs.

## Assessment procedures

- **AGT-110-A1 - Examine:** Verify approved permissions and enforcement points for sampled agents.
- **AGT-110-A2 - Test:** Attempt actions, targets, and delegation outside approved scope.
- **AGT-110-A3 - Test:** Verify resource and duration limits under adversarial conditions.

## Metrics
