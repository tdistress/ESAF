# AGT-100 Agent Accountability and Identity

## Requirement

The organization shall assign each agent a unique managed identity, accountable owner, approved purpose, risk classification, lifecycle state, operating boundary, and attributable deployment record before the agent can act.

## Intent

Agents require accountability as acting identities rather than being treated only as model sessions.

## Applicability

Applies to assistants, workflow agents, coding agents, autonomous services, and agents embedded in products or platforms.

## Implementation guidance

Record agent identity separately from model and user identity. Link instances to owner, capability, version, tools, data, memory, environment, supervisor, and retirement. Prevent anonymous agent action.

## Expected evidence

- Agent inventory, identity records, ownership, purpose, classification, deployment, and lifecycle history.

## Assessment procedures

- **AGT-100-A1 - Examine:** Verify complete identity and accountability records for sampled agents.
- **AGT-100-A2 - Test:** Trace agent actions to unique identity, deployment, and owner.
- **AGT-100-A3 - Test:** Identify active agents absent from the authoritative inventory.
