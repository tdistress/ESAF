# AGT-130 Agent Memory and State Governance

## Requirement

The organization shall classify, authorize, isolate, validate, limit, retain, correct, and delete agent memory and state according to purpose, identity, tenant, source, sensitivity, reliability, and lifecycle.

## Intent

Persistent agent memory can leak data, preserve malicious instructions, and influence future behavior beyond the original interaction.

## Applicability

Applies to short-term and long-term memory, plans, scratchpads, summaries, profiles, caches, checkpoints, and learned preferences.

## Implementation guidance

Separate tenants and identities, preserve source and confidence, restrict writes, scan untrusted memory, expire unnecessary state, provide correction, and prevent memory from silently expanding authority.

## Expected evidence

- Memory architecture, classification, write and read policy, isolation, retention, correction, deletion, and adversarial tests.

## Assessment procedures

- **AGT-130-A1 - Examine:** Verify controls for each memory and state type.
- **AGT-130-A2 - Test:** Attempt cross-user, cross-tenant, and unauthorized memory access or write.
- **AGT-130-A3 - Test:** Insert malicious memory and verify validation, isolation, and deletion.
