# API-110 AI API Security

## Requirement

The organization shall authenticate, authorize, validate, encrypt, limit, version, log, monitor, and securely deprecate APIs that expose or connect AI capabilities, models, data, tools, or administrative functions.

## Intent

AI APIs are high-value boundaries for data, capability, cost, and privileged action.

## Applicability

Applies to internal, external, provider, model, inference, management, tool, callback, streaming, and batch interfaces.

## Implementation guidance

Use explicit contracts, scoped credentials, object and action authorization, schema validation, replay protection, rate limits, bounded payloads, secure errors, inventory, and retirement notices.

## Expected evidence

- API inventory, contracts, identity and authorization policy, validation, encryption, limits, logs, tests, and deprecation records.

## Assessment procedures

- **API-110-A1 - Examine:** Verify security controls for representative API types.
- **API-110-A2 - Test:** Attempt unauthorized objects, actions, versions, and oversized or malformed requests.
- **API-110-A3 - Test:** Validate logging, rate limits, replay protection, and deprecation behavior.
