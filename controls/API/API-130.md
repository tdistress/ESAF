# API-130 MCP and Orchestration Security

## Requirement

The organization shall authenticate, authorize, inventory, isolate, validate, and monitor MCP servers, clients, orchestration components, context exchange, capability discovery, and delegated calls according to their trust and impact.

## Intent

Protocol and orchestration layers dynamically expose data and actions and can propagate authority across multiple systems.

## Applicability

Applies to Model Context Protocol and comparable context, tool-discovery, agent-communication, and orchestration mechanisms.

## Implementation guidance

Use approved registries, pinned server identity, transport protection, scoped authorization, explicit capability allowlists, schema validation, context minimization, origin metadata, sandboxing, and end-to-end tracing.

## Expected evidence

- Component inventory, trust model, identity configuration, capability policy, context-flow records, validation, isolation, and traces.

## Assessment procedures

- **API-130-A1 - Examine:** Verify identities, capabilities, trust boundaries, and context controls.
- **API-130-A2 - Test:** Introduce an unapproved server or capability and verify rejection.
- **API-130-A3 - Test:** Trace a delegated call across components to final authorization and outcome.
