# API-120 AI Tool and Plugin Governance

## Requirement

The organization shall inventory, approve, authenticate, authorize, constrain, validate, monitor, and retire every tool or plugin that an AI capability can invoke.

## Intent

Tools convert model output into actions and can create impact beyond the model's own boundary.

## Applicability

Applies to native tools, functions, plugins, connectors, actions, scripts, browsers, code execution, databases, and business-system integrations.

## Implementation guidance

Record owner, purpose, input and output schema, permissions, side effects, data access, target, rate and resource limits, approval needs, and failure behavior. Authorize at the tool and target system, not only in prompts.

## Expected evidence

- Tool registry, approvals, schemas, permissions, tests, monitoring, change history, and retirement evidence.

## Assessment procedures

- **API-120-A1 - Examine:** Verify registry and approval completeness for sampled tools.
- **API-120-A2 - Test:** Attempt unauthorized parameters, targets, and side effects.
- **API-120-A3 - Test:** Disable a tool and verify invocation is prevented and logged.

## Metrics

|---|---|---|
