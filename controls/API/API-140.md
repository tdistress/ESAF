# API-140 External AI Service Integration

## Requirement

The organization shall define and enforce the security, privacy, data use, retention, training, residency, availability, change, incident, assurance, continuity, and exit requirements for each external AI service integration.

## Intent

External services create shared responsibilities and dependencies that internal controls alone cannot resolve.

## Applicability

Applies to hosted models, AI SaaS, external APIs, tool providers, data processors, evaluation services, and subcontracted operations.

## Implementation guidance

Document shared responsibility and data flow, validate contractual and technical settings, restrict provider training and retention where required, monitor material changes, obtain assurance, and test provider failure and exit.

## Expected evidence

- Due diligence, contract, architecture, configuration, shared-responsibility matrix, assurance, monitoring, continuity, and exit records.

## Assessment procedures

- **API-140-A1 - Examine:** Verify that required provider terms and technical settings are documented and enforced.
- **API-140-A2 - Test:** Confirm actual data retention, training, residency, and access settings where testable.
- **API-140-A3 - Examine:** Trace supplier changes and incidents to risk and governance review.
