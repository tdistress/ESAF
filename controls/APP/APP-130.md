# APP-130 Session, Tenant, and Memory Isolation

## Requirement

The organization shall isolate user, tenant, session, conversation, cache, and memory state so that identities can access only context and retained state authorized for their purpose and scope.

## Intent

State leakage can expose data, instructions, identity context, and agent memory across users or tenants.

## Applicability

Applies to single-user and multi-tenant applications, shared caches, conversation history, personalization, long-term memory, and agent state.

## Implementation guidance

Bind state to authenticated identity and tenant, enforce authorization on every retrieval, use isolated namespaces and encryption, minimize retention, prevent identifier guessing, and clear ephemeral state on termination.

## Expected evidence

- State model, isolation design, namespace and authorization configuration, retention, deletion, and cross-tenant test results.

## Assessment procedures

- **APP-130-A1 - Examine:** Verify identity and tenant binding for each state store.
- **APP-130-A2 - Test:** Attempt cross-user and cross-tenant access to sessions, caches, and memory.
- **APP-130-A3 - Test:** Verify state expiration and deletion after defined lifecycle events.
