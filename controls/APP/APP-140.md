# APP-140 AI Software Assurance

## Requirement

The organization shall apply controlled secure-development, review, testing, dependency, build, release, vulnerability, and change practices to AI application code, prompts, workflows, configurations, and AI-generated artifacts.

## Intent

AI applications combine conventional software risk with prompts, chains, configurations, generated code, and rapidly changing dependencies.

## Applicability

Applies to internally built and materially configured AI applications, pipelines, prompt libraries, workflows, tests, and deployment artifacts.

## Implementation guidance

Use source control, peer review, protected builds, dependency inventories, static and dynamic testing, secret scanning, code signing, environment separation, and security gates. Subject AI-generated code to the same or stronger review as human-authored code.

## Expected evidence

- Development standard, repositories, reviews, pipeline configuration, scans, tests, approvals, dependency records, and release evidence.

## Assessment procedures

- **APP-140-A1 - Examine:** Verify secure-development controls across code, prompts, workflows, and configurations.
- **APP-140-A2 - Test:** Trace a sampled release from approved source through build and deployment.
- **APP-140-A3 - Examine:** Verify remediation or acceptance of sampled security findings.
