# APP-110 Input and Context Protection

## Requirement

The organization shall identify, classify, validate, constrain, and separate instructions, user input, retrieved content, tool output, memory, and other context according to trust and authority before model processing.

## Intent

Models may treat untrusted content as instructions unless applications preserve trust boundaries and authority.

## Applicability

Applies to prompts, uploads, retrieved documents, web content, messages, tool results, multimodal input, system instructions, and memory.

## Implementation guidance

Separate system and developer instructions from untrusted content, constrain input type and size, sanitize active content, preserve source metadata, limit context, and test indirect prompt injection. Do not rely on prompt wording as the sole security boundary.

## Expected evidence

- Input inventory, trust classification, context assembly design, validation rules, filtering configuration, and adversarial test results.

## Assessment procedures

- **APP-110-A1 - Examine:** Verify trust classification and separation for all context sources.
- **APP-110-A2 - Test:** Submit direct and indirect adversarial inputs and observe control behavior.
- **APP-110-A3 - Test:** Attempt to override higher-authority instructions through untrusted context.
