# MOD-130 Model Change and Version Control

## Requirement

The organization shall uniquely version, authorize, test, deploy, monitor, and support rollback for model, fine-tuning, weight, parameter, safety-setting, system-instruction, and material provider-version changes.

## Intent

Controlled releases prevent untested model behavior and permit traceability and recovery.

## Applicability

Applies to internal and supplier-controlled model changes, including silent or automatic provider upgrades.

## Implementation guidance

Pin versions where feasible, record immutable identifiers, compare behavior before release, define canary and rollback criteria, monitor supplier notices, and treat unannounced changes as incidents or exceptions according to risk.

## Expected evidence

- Version records, change approvals, comparison tests, deployment records, rollback tests, supplier notices, and monitoring.

## Assessment procedures

- **MOD-130-A1 - Examine:** Verify authorization and testing for sampled model changes.
- **MOD-130-A2 - Test:** Compare deployed versions with approved registry and configuration records.
- **MOD-130-A3 - Observe:** Observe a rollback or controlled model-version transition.
