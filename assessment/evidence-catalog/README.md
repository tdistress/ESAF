# ESAF-1500 Evidence Catalog (Draft starter)

**Status:** Draft starter  
**Issue:** [#116](https://github.com/tdistress/ESAF/issues/116)

This directory is a non-normative starter catalog of ESAF-1500 evidence types
and expectations. It reuses the shared evidence contract; it does not define a
parallel evidence model.

- [ESAF-1500 evidence catalog](ESAF-1500-evidence-catalog.md) lists the closed
  `evidence_type` values, required contract fields, quality attributes, and
  profile-neutral example uses.
- Authoritative semantics remain in [ESAF-1500](../ESAF-1500.md) and
  [`../schema/evidence-record.schema.json`](../schema/evidence-record.schema.json).

## Nonclaims

This catalog is Draft starter material only. Using catalog entries does not
establish certification, compliance, equivalence, endorsement, assurance,
production readiness, or lifecycle approval for any Draft ESAF artifact.
