# Project attribution design

## Purpose

Record Eric Amos as the author, project maintainer, and lead contributor to ESAF. "Hearst" is an affiliation only and does not imply that Hearst owns, sponsors, or endorses the project.

## Scope

Update the repository's canonical attribution files:

- `AUTHORS.md` lists Eric Amos (Hearst) as Author and Project Maintainer.
- `CONTRIBUTORS.md` lists Eric Amos (Hearst) as Lead Contributor.
- `PROJECT_CHARTER.md` identifies Eric Amos (Hearst) as the Project Maintainer in the document owner field.

Do not add this attribution to normative ESAF publications or repeat it in `README.md`. Leave `.github/CODEOWNERS` unchanged because it already assigns the repository to `@tdistress`.

## Validation

Confirm that all three canonical files use the exact name and affiliation, that their roles do not conflict, and that the branch contains no unrelated changes or whitespace errors.
